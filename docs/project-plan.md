# 项目推进基线

## 第一阶段：数据与口径

- 定义赛事、球队、比赛、比分、阶段和晋级关系的数据字典。
- 明确常规时间、加时赛、点球大战的表达与查询规则。
- 建立球队中英文名、历史名称与别名映射。
- 准备可重复执行的数据清洗与导入脚本。

## 第二阶段：检索与 Agent

- 实现结构化事实查询与 Chroma 语义检索。
- 加入 BGE 重排、证据去重与引用组装。
- 使用 LangGraph 完成意图判断、路由、失败回退和回答生成。
- 建立可观测日志，记录查询、召回、重排和答案来源。

## 第三阶段：接口与前端

- 固化 FastAPI/OpenAPI 契约。
- 实现问答、比赛详情、球队关系和来源查看接口。
- 使用 Vue 3 构建页面，使用 D3.js 展示胜负与晋级关系。

## 第四阶段：评测与交付

- 建立事实准确率、引用覆盖率、召回率和响应时间指标。
- 覆盖典型问题、歧义问题、无答案问题和对抗性问题。
- 准备演示脚本、部署说明、开发文档和小组答辩材料。
