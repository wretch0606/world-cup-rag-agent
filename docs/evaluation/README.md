# Evaluation deliverables

- `worldcup-rag-evaluation-template.xlsx`: editable run log and formula-driven metric summary.
- `experiment-report-outline.md`: experiment report structure and ablation matrix.
- `error-case-template.md`: repeatable failure analysis template.
- `presentation-outline.md`: page-by-page defense presentation plan.

The workbook is a shared template. Use a new `run_id` for each configuration rather than creating files named `final-v2`, `final-v3`, and so on. Formal results should record the data version, prompt version, model, retrieval settings and trace IDs.
