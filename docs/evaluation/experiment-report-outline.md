## 1. 研究目标

1. 验证系统能否正确区分精确比分、关系、点球、比较、总结和越界问题。
2. 验证结构化事实与 Chroma 证据融合能否降低事实错误。
3. 比较 query rewrite、reranker、Top-K 和 Prompt 版本对结果的影响。
4. 验证答案能否回溯到 `source_id`，并正确处理无结果和来源冲突。

### 4.1 六类 Prompt

### 4.2 事实优先级

1. 结构化比赛事实决定比分、阶段、结果和点球口径。
2. Chroma 文本补充解释、背景和来源证据。
3. 两者冲突时输出告警，不自动选择更像答案的文本。

## 5. 评测指标

| 指标 | 计算方式 | 建议目标 |
|---|---|---:|
| Intent Accuracy | 正确意图数 / 已完成题数 | ≥90% |
| Fact Accuracy | 事实完全正确题数 / 已评分题数 | ≥95% |
| Citation Coverage | 来源覆盖题数 / 已评分题数 | ≥95% |
| Penalty Scope Accuracy | 点球口径正确题数 / 点球相关题数 | 100% |
| Faithfulness | 人工评分均值（1-5） | ≥4.5 |
| Completeness | 人工评分均值（1-5） | ≥4.0 |
| Readability | 人工评分均值（1-5） | ≥4.0 |
