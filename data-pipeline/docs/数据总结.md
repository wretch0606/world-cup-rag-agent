## 八、数据文件说明

| 文件 | 格式 | 用途 |
|------|------|------|
| `worldcup.db` | SQLite | 结构化赛事数据库，所有 964 场比赛 |
| `match_facts.json` | JSON | 964 条中文事实叙述 + metadata，供 Chroma 入库 |
| `cleaning_report.json` | JSON | 清洗质量报告 |
| `team_aliases.json` | JSON | 85 支球队的别名映射表 |
| goals 表（SQLite） | 数据库表 | 2,720 条进球记录，按 `match_id` 关联比赛 |

## 九、数据字段速查

每场比赛包含以下信息：

```
赛事定位：match_id / tournament_year / match_date / stage / group_name / venue
参赛双方：home_team_id / away_team_id
比分字段：home_score_90 / away_score_90 / home_score_et / away_score_et / home_penalties / away_penalties
结果字段：winner_team_id / result_type / score_display
来源追溯：source_id / data_version
```

## 十、已知限制

1. 加时赛的 90 分钟单独比分缺失——数据源只提供最终比分
2. 点球大战的正式比分和点球比分在早期届次（1994 年以前）可能不完整
3. 球员、进球者、红黄牌等个人数据不在本数据集中
